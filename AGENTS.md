# Project Instructions

## General
- Work only on the requested task.
- Inspect only relevant files first.
- Do not scan the entire repository unless necessary.
- Do not modify unrelated code.
- Preserve existing functionality and design unless explicitly asked to change it.
- Reuse existing components, utilities, styles, and patterns where possible.

## Editing
- Prefer minimal targeted changes.
- Do not perform unnecessary refactors.
- Do not rewrite entire files when a small edit is enough.
- Keep existing naming conventions and project structure.

## Validation
- After editing, check only the affected functionality.
- Run targeted tests/lint/build commands instead of unnecessary full-project checks unless needed.
- Fix errors caused by your changes before finishing.

## Response
- Keep explanations concise.
- Report:
  1. files changed
  2. what changed
  3. validation performed

## Efficiency
- Do not search for additional problems or improvements beyond the requested task.
- Stop once the requested task is correctly completed.
- Avoid repeated inspection of unchanged files.
- For simple UI/CSS changes, do not run full-project builds unless necessary.
